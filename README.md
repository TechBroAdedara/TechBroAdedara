# Adedara Adeloro Courage

Backend developer based in Lagos, Nigeria. I build APIs and real-time systems with Python, FastAPI, .NET, and TypeScript.

I'm interested in backend engineering, distributed systems, and tools that remove repetitive work. Most of my recent work is around authentication, data modelling, real-time communication, and deployment.

## Featured projects

### [Intern Compass](https://github.com/Intern-Compass/backend)
FastAPI backend for an intern onboarding platform. Handles authentication, profiles, projects, and community features with PostgreSQL, SQLAlchemy, Alembic, Docker, and a pytest suite.

### [Ave Geofence System](https://github.com/AveGeofencing/Ave)
FastAPI and SQLAlchemy backend for geofence-based attendance. Supports fence creation, student check-in, real-time updates, session auth, and Docker deployment.

### [Hatt Chat](https://github.com/TechBroAdedara/Hatt-Chat-App)
Real-time chat application built with .NET 9, ASP.NET Core, EF Core, and MySQL. Includes user authentication, private and group conversations, and a REST API.

### [Meeting Workbook Generator](https://github.com/TechBroAdedara/Meeting-Workbook-Generator)
Python CLI that scrapes meeting workbook content and generates formatted Word schedules in seconds. Uses HTTPX, BeautifulSoup, and python-docx.

### [Custom WebSocket Managers](https://github.com/TechBroAdedara/custom-websocket-implementation)
A WebSocket manager architecture with separate chat and notification managers, built to reduce server load by disconnecting chat connections when they are not needed.
