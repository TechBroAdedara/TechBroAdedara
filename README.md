# Adedara Adeloro Courage

Backend developer based in Lagos, Nigeria. I build APIs and event-driven systems with Python, FastAPI, .NET, and TypeScript.

I'm interested in backend engineering, distributed systems, and tools that remove repetitive work. My recent work focuses on authentication, data modelling, real-time communication, and deployment.

## Featured projects

### [Intern Compass](https://github.com/TechBroAdedara/intern-compass-backend)
FastAPI backend for an intern onboarding and supervision platform. Handles authentication, profiles, projects, tasks, and skill-based supervisor matching with PostgreSQL, SQLAlchemy, Alembic, and Docker.

### [Ave Geofence System](https://github.com/AveGeofencing/Ave)
FastAPI and SQLAlchemy backend for geofence-based student attendance. Supports fence creation, check-in, AWS face-liveness and face-match verification, session auth, and Docker deployment.

### [Hatt Chat](https://github.com/TechBroAdedara/Hatt-Chat-App)
REST API for a chat platform built with .NET 9, ASP.NET Core, EF Core, and MySQL. Includes JWT authentication, user discovery, friend requests, and message history/sending, with a SignalR foundation for real-time delivery.

### [Meeting Workbook Generator](https://github.com/TechBroAdedara/Meeting-Workbook-Generator)
FastAPI web app that scrapes meeting workbook content and generates formatted Word schedules in seconds. Uses aiohttp, BeautifulSoup, and python-docx.

### [Custom WebSocket Managers](https://github.com/TechBroAdedara/custom-websocket-implementation)
WebSocket manager architecture with separate chat and notification managers, built to keep chat connections independent from always-on notifications.
